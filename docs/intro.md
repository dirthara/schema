# Introduction

Dirthara Schema describes a database schema once and compiles the DDL for the
database you point it at: MySQL, PostgreSQL, SQLite, or SQL Server.

:::note
This package is early in its `0.1` line. Pages describing the definition API and
its options land here as that API does.
:::
